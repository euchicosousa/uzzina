DS28 · Conferência dos neutros novos

Todas as cores neutras saem do fundo do tema (cor pai).

Claro

Escuro

Fórmulas dos neutros por modo (valores de novo/tailwind-novo.css)

Claro

  • Texto principal = fundo L −0,96 e C −0,002 (mínimo 0)
  • Texto secundário = fundo L −0,512 e C −0,001 (mínimo 0)
  • Cartão = fundo L −0,02
  • Popover = fundo L +0,02
  • Campo = fundo L −0,04
  • Borda = fundo L −0,07
  • Ação = fundo L +0,02
  • Ação (hover) = fundo L +0,10
  • Secundário = fundo L −0,036
  • Secundário (hover) = fundo L −0,083
  • Texto suave = texto principal a 40%
  • Borda do container = texto principal a 5%

Escuro

  • Texto principal = fundo L +0,80 e C −0,01 (mínimo 0)
  • Texto secundário = fundo L +0,549 e C −0,007 (mínimo 0)
  • Cartão = fundo L +0,05
  • Popover = fundo L −0,03
  • Campo = fundo L +0,02
  • Borda = fundo L +0,10
  • Ação = fundo L +0,10
  • Ação (hover) = fundo L +0,20
  • Secundário = fundo L +0,098 e C −0,002 (mínimo 0)
  • Secundário (hover) = fundo L +0,133 e C −0,002 (mínimo 0)
  • Texto suave = texto principal a 40%
  • Borda do container = texto principal a 10%

Semânticas (erro, aviso, sucesso, info) são valores fixos por modo, sem fórmula de fundo. Os fundos de alerta são mistura com o fundo: 10% no claro e 30% no escuro.
